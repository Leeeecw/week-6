# Attention과 생성 결함 위치 비교 실험 결과 분석

**같은 입력 이미지로 생성한 5장에서, Attention이 강한 위치와 결함처럼 보이는 위치는 일부만 일치했다.** 작은 틈이나 표면 변화는 나타났지만, 목표로 한 큰 균열과 내부 노출은 뚜렷하지 않았다.

## 1. 실험 의도

결함이 오브젝트 바깥에 생성되는 현상을 살펴보기 위해, **모델이 `crack`이라는 단어와 강하게 연결한 위치에 실제로 균열이 나타나는지** 확인했다.

- **생성 이미지:** 실제로 결함처럼 보이는 위치를 확인한다.
- **Attention 지도:** `crack` 단어와 강하게 연결되는 위치를 확인한다.
- **오버레이:** 두 위치가 겹치는지 비교한다.

이를 통해 배경에 대한 높은 Attention이 오브젝트 밖 결함 생성과 함께 나타나는지, Attention을 결함 위치의 참고 자료로 사용할 수 있는지 알아보고자 했다.

## 2. 실험 조건

| 항목 | 설정 |
|---|---|
| 입력 | 정상 헤이즐넛 이미지 1장, 512×512 |
| 모델 | `runwayml/stable-diffusion-v1-5` 기반 AnomalyAny |
| 생성 수 | seed별 1장, 총 5장 |
| Seed | `42`, `123`, `2026`, `7`, `99` |
| 확산 단계 설정 | `NUM_DIFFUSION_STEPS = 50` |
| Guidance scale | `12.5` |
| 초기 이미지 관련 설정 | `init_image_guidance_scale = 0.3` |
| 최적화 설정 | `scale_factor = 50` |
| 편집 영역 마스크 | `mask_image = None` |
| 관찰할 단어 | `crack` |
| Attention 추출 | 마지막 UNet 실행의 조건부 cross-attention, 선택 단어의 head·layer 평균 |
| Attention 해상도 | 16×16, 모든 seed에 공통 색상 범위 적용 |

프롬프트는 다음과 같다.

- **생성:** `a photo of a hazelnut with a crack on it`
- **정상:** `a photo of a hazelnut`
- **상세:** `a photo of a hazelnut with a large, jagged crack exposing the interior.`

노트북에 저장된 로그에서 seed 5개의 생성 완료와 비교 그림 출력을 확인했다. 아래 분석은 저장된 출력에 대한 육안 관찰이며, 모델을 다시 실행한 결과는 아니다.

## 3. 결과 분석

### 원본과 생성 이미지

![원본과 seed별 생성 이미지 비교](<images\generativeAI\원본_생성이미지_비교.png>)

원본은 노트북의 입력 이미지이며, 생성 이미지는 저장된 비교 그림의 왼쪽 패널을 잘라 구성했다. 비교를 위한 표시 크기 조정이 포함되어 있어 원본 생성 파일을 이용한 픽셀 단위 평가는 수행하지 않았다.

| Seed | 생성 이미지에서 관찰한 변화 | Attention과의 관계 |
|---|---|---|
| **42** | 상단 표면과 경계가 거칠어지고 몸체 무늬가 변했다. 큰 균열은 불분명하다. | 오브젝트 위쪽·오른쪽 배경에도 강한 반응이 있어 변화 위치와 부분적으로만 겹친다. |
| **123** | 상단 경계에 밝은 선과 갈라짐처럼 보이는 변화가 나타났다. | 가장 강한 반응은 왼쪽 배경에 있다. 그 위치에서 뚜렷한 균열은 확인하기 어렵다. |
| **2026** | 상단 왼쪽 아래에 검은 틈과 작은 구멍처럼 보이는 변화가 나타났다. | 해당 부근에도 반응하지만 배경에도 분산되어 있다. 결함 후보와 부분적으로 겹친다. |
| **7** | 상단 경계가 진해지고 몸체의 세로 무늬가 강조됐다. 배경 변화도 크다. | 왼쪽 외곽과 배경에도 반응하며, 뚜렷한 새 균열과 연결하기 어렵다. |
| **99** | 상단 오른쪽 경계에 작은 벗겨짐처럼 보이는 변화가 나타났다. | 해당 부근과 강한 반응이 비교적 잘 겹친다. 다만 큰 균열이나 내부 노출은 불분명하다. |

### Attention과 이미지의 위치 관계

![생성 이미지와 Attention 및 오버레이 비교](images\generativeAI\Attention_비교.png)

**일부 위치는 겹쳤지만, 최대 Attention 위치가 항상 결함 위치를 가리키지는 않았다.** Seed 99는 상단 오른쪽의 변화와 반응이 비교적 잘 겹쳤다. 반면 seed 123은 배경에 가장 강하게 반응했지만, 그곳에 명확한 균열은 보이지 않았다.

**배경 변화와 배경 결함은 구분해야 한다.** 일부 이미지에서 배경의 무늬나 밝기가 달라졌지만, 이것만으로 오브젝트 밖에 균열이 생성됐다고 판단할 수는 없다. 이번 결과에서는 높은 배경 Attention과 외부 균열 생성의 관계를 확정하지 못했다.

**상세 프롬프트의 요구는 충분히 구현되지 않았다.** 큰 균열과 내부 노출보다 기존 경계 강조, 작은 틈, 표면 무늬 변화가 주로 관찰됐다.

## 4. 왜 이런 결과가 나왔는가?

### 코드에서 확인한 조건

- **Attention은 단어와 위치의 연결을 보여준다.** 밝은 부분을 실제 균열의 존재 여부나 균열일 확률로 해석할 수는 없다. 최종 이미지에는 여러 단어와 생성 단계의 영향이 함께 반영된다.
- **마지막 실행의 16×16 지도만 비교했다.** 여러 head·layer를 평균한 값이므로 세부 반응이 합쳐지며, 가느다란 균열의 경계를 정확하게 나타내기 어렵다. 확대와 보간은 표시를 부드럽게 할 뿐 원래의 위치 정밀도를 높이지 않는다. 생성 초·중반의 반응도 이 그림에는 포함되지 않는다.
- **편집 영역을 제한하지 않았다.** `mask_image=None`이므로 오브젝트 내부만 변경하도록 제한하지 않았다. 배경도 달라질 수 있는 조건이다.

### 결과를 설명할 수 있는 가설

| 가능한 원인 | 이번 결과와 연결한 해석 |
|---|---|
| **기존 경계를 균열처럼 활용** | 원본에도 상단을 가로지르는 경계가 있다. 새롭고 큰 균열을 만들기보다 기존 경계를 진하게 하거나 벌어진 듯 표현했을 가능성이 있다. |
| **원본 유지와 큰 변형 사이의 영향** | `init_image_guidance_scale=0.3`은 생성 시작 시점을 조절한다. 원본에서 비교적 적게 변형하는 조건이 큰 파손보다 작은 표면 변화로 이어졌을 가능성이 있다. 해당 값만 변경한 비교 실험으로 확인해야 한다. |
| **마지막 Attention과 생성 과정의 차이** | 균열 형성에 관련된 반응이 앞선 단계에 있었다면, 마지막 지도만으로는 이를 확인할 수 없다. 중간 이미지와 Attention을 함께 관찰해야 한다. |

위 가설들은 현재 결과에 대한 가능한 설명이다. 마스크, 생성 조건, 관찰 시점을 각각 바꿔 비교하지 않았으므로 원인별 영향을 확정할 수는 없다.

## 5. 회고와 한계

- **표면 변화를 모두 결함 생성 성공으로 세면 안 된다.** 원본에 있던 경계·무늬의 강조와 새로 생긴 균열을 구분해야 한다.
- **Attention과 생성 이미지를 함께 봐야 한다.** 히트맵의 밝은 부분을 먼저 결함이라고 가정하면 해석이 편향될 수 있다. 생성 이미지에서 결함 후보를 먼저 확인하는 편이 적절하다.
- **이번 관찰의 범위는 이미지 1개와 seed 5개다.** 다른 제품이나 결함에서도 같은 관계가 나타나는지는 확인하지 않았다.
- **정량적인 위치 일치율은 계산하지 않았다.** 직접 확인한 결함 좌표가 비어 있고(`DEFECT_POINTS_BY_SEED = {}`), 정답 결함 마스크도 없다. 별도 저장된 원본 Attention 배열과 생성 이미지 파일은 첨부 노트북에 포함되어 있지 않아, 이번 분석은 내장된 비교 그림을 기준으로 했다.
