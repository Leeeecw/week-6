# AE 개선 실험: 아이디어·결과 분석·회고

> **핵심 결과:** AE의 입력·출력 범위를 맞추고 상위 1% 오차를 사용하자 AUROC가 **0.2663 → 0.9245**로 높아졌다.  
> 다만 기존 PaDiM의 **0.9602**에는 미치지 못했다.

## 1. 개선 방식 아이디어

### 1.1. 입력·출력 범위 일치

기존 AE는 ImageNet 정규화가 적용된 이미지를 입력받지만, 디코더의 `Sigmoid` 출력은 0~1로 제한된다. 입력에는 음수와 1보다 큰 값이 포함될 수 있어 정상 이미지도 입력과 같은 값으로 복원하기 어렵다.

이를 해결하기 위해 AE의 구조와 출력 활성화는 유지하고, 입력을 `ToTensor`의 0~1 범위로 맞췄다. 두 AE는 같은 초기 시드·배치 순서·학습 조건으로 비교했다. PaDiM에는 기존 ImageNet 정규화를 유지했다.

### 1.2. 상위 영역 오차로 작은 결함 강조

작은 결함은 이미지 전체 평균 오차에서 희석될 수 있다. 개선 AE에서 RGB 채널의 MSE를 평균한 공간 오차 지도를 만들고, 다음 세 점수를 비교했다.

| 점수 | 계산 방법 | 확인하려는 효과 |
|---|---|---|
| 전체 평균 | 모든 위치의 평균 오차 | 기존 점수 방식 유지 |
| 상위 1% | 오차가 큰 1% 위치의 평균 | 작은 고오차 영역 강조 |
| 상위 5% | 오차가 큰 5% 위치의 평균 | 더 넓은 이상 영역 반영 |

세 점수는 동일한 개선 AE에서 계산했다. 기존 PaDiM은 특징·통계·점수 설정을 바꾸지 않은 비교 기준으로 사용했다.

## 2. 결과 분석

### 실험 조건

VisA `pcb4`의 정상 이미지 **804장으로 학습**하고, 정상 **201장·이상 100장으로 시험**했다.  
입력 크기 256×256, 배치 크기 16, AE 학습 50 epoch, 시드 42를 사용했다.

| 방식 | AUROC | AUPRC | Oracle Best F1 |
|---|---:|---:|---:|
| 기존 AE · 전체 평균 | 0.2663 | 0.2263 | 0.5249 |
| 개선 AE · 전체 평균 | 0.9127 | 0.7632 | 0.7899 |
| **개선 AE · 상위 1%** | **0.9245** | **0.7913** | **0.8073** |
| 개선 AE · 상위 5% | 0.9218 | 0.7872 | 0.8035 |
| 기존 PaDiM | 0.9602 | 0.8973 | 0.8837 |

AUROC는 정확도와 다른 지표다. `Oracle Best F1`은 시험 세트에서 가장 좋은 임계값을 선택한 참고값으로, 미리 고정한 운영 임계값의 성능과 구분한다.

### 2.1. 기존 AE와 개선 AE 비교

**가장 큰 개선은 입력 범위를 수정했을 때 나타났다.** 점수를 전체 평균으로 유지해도 AUROC가 0.2663에서 0.9127로, AUPRC가 0.2263에서 0.7632로 높아졌다. 이번 조건에서는 입력·출력 범위의 불일치가 낮은 성능의 주요 원인 중 하나였다는 해석을 뒷받침한다.

범위를 수정한 뒤 상위 1% 오차를 사용하면 평균 방식보다 AUROC가 약 **1.2%p**, AUPRC가 약 **2.8%p** 더 높았다. 국소적인 이상 신호가 전체 평균에서 희석되는 현상을 줄였을 가능성이 있다. 다만 고오차 영역이 실제 결함과 일치하는지는 마스크를 이용한 별도 확인이 필요하다.

상위 1%가 상위 5%보다 높았지만 AUROC 차이는 0.0027로 작았다. 단일 실행만으로 상위 1%가 항상 우수하다고 판단하기는 어렵다.

복원 그림에서도 개선 AE는 기존보다 배경과 PCB의 색상·구조를 더 잘 보존했다. 일부 부품 경계는 여전히 흐릿했다. 아래 오차 그림은 같은 RGB 공간에서 계산한 표시용 결과이며, 결함 위치 정확도를 평가한 결과는 아니다.

![기존 AE와 개선 AE의 복원 결과](<image/AE_복원_비교.png>)

두 모델의 학습 손실은 입력 단위가 달라 숫자 자체를 직접 비교하지 않았다. 개선 판단에는 같은 시험 라벨에 대한 AUROC·AUPRC와 복원 결과를 사용했다.

### 2.2. 개선 AE와 기존 PaDiM 비교

개선 AE 중 가장 높은 상위 1% 방식도 기존 PaDiM보다 세 지표 모두 낮았다. 노트북의 차이 표를 기준으로 AUROC는 약 **3.6%p**, AUPRC는 **10.6%p**, Oracle Best F1은 약 **7.6%p** 차이가 남았다.

ROC 곡선에서도 낮은 오탐률 구간에서 PaDiM이 더 높은 탐지율을 보이는 구간이 확인된다. 따라서 이번 데이터와 설정에서는 **기존 PaDiM이 더 높은 분리 성능을 보였고, AE 개선은 기존 AE의 문제를 해결하는 데 효과적이었다**고 해석할 수 있다.

![개선 AE와 기존 PaDiM의 ROC 비교](<image/개선AE_기존PaDiM_ROC.png>)

PaDiM은 사전학습 CNN 특징을 사용하고, AE는 정상 이미지의 재구성을 학습한다. 학습 방식과 사전 지식이 다르므로, 이 결과를 모든 상황에서의 모델 우열로 일반화하지는 않는다.

## 3. 회고

**잘한 점:** 모델을 복잡하게 바꾸기 전에 입력과 출력의 범위를 점검했다. 구조를 유지한 비교에서 큰 변화가 나타나, 기본적인 전처리의 일관성이 중요하다는 점을 확인했다. 입력 범위 수정과 점수 집계를 나누어 비교한 덕분에 각각의 효과도 구분할 수 있었다.

**아쉬운 점:** 실험은 한 카테고리·한 분할에 한정되었다. AE의 상위 1%와 5%처럼 작은 차이가 반복되는지는 확인하지 못했다. 시험 데이터에서 임계값을 선택한 F1도 실제 운영 성능으로 보기 어렵다.

**배운 점:** 정상 이미지를 잘 복원하도록 만드는 것과 결함을 잘 구분하는 것은 함께 확인해야 한다. 이번에는 입력 범위 수정이 복원과 탐지 성능을 모두 개선했지만, 그 결과만으로 기존 PaDiM의 성능까지 넘어선 것은 아니었다.
