# Stable Diffusion 문장형·키워드형 프롬프트 비교 결과

- **텍스트 생성:** 탑승 관계가 확인된 결과는 문장형 **2/5장**, 키워드형 **5/5장**이었다.
- **인페인팅:** 열린 상자와 내부 금화가 가장 명확하게 보이는 결과는 두 형식 모두 **seed 7**이었다.
- **생성 시간 중앙값:** 텍스트 생성은 두 형식 모두 **1.52초/장**, 인페인팅은 문장형 **2.43초/장**, 키워드형 **2.45초/장**이었다.

## 1. 실험 조건

각 실험에서 같은 seed 5개를 두 프롬프트에 적용했다. 모델·해상도·step·guidance·negative prompt는 해당 실험의 두 조건 사이에서 동일하게 유지했다.

| 항목 | 텍스트 이미지 생성 | 인페인팅 |
|---|---|---|
| 모델 | runwayml/stable-diffusion-v1-5 | sd-legacy/stable-diffusion-inpainting |
| 생성 수 | 문장형 5장 + 키워드형 5장 | 문장형 5장 + 키워드형 5장 |
| Seed | 42, 123, 2026, 7, 99 | 42, 123, 2026, 7, 99 |
| 해상도 | 512×512 | 512×512 |
| 생성 step | 30 | 50 |
| Guidance scale | 8.5 | 8.5 |
| 정밀도 | FP16 | FP16 |
| 추가 입력 | 없음 | 같은 해변 이미지와 중앙 타원형 마스크 |
| Strength | 해당 없음 | 1.0 |

노트북 메타데이터의 GPU 표기는 A100이며, 실행 로그에서는 CUDA 사용을 확인했다. 저장된 버전 출력은 diffusers 0.40.0, transformers 5.18.0이다.

이 문서는 노트북에 저장된 마지막 실행 출력과 비교 이미지를 분석했다. 이미지를 새로 생성하지 않았으며, 아래 내용 판단은 자동 평가 점수가 아닌 **육안 관찰**이다.

## 2. 텍스트 이미지 생성 결과

### 비교 프롬프트

**문장형**

> A photo of man riding a horse in the moon wearing astronaut outfits

**키워드형**

> man, riding, horse, moon, space suit

![텍스트 이미지 생성 비교: 위쪽 문장형, 아래쪽 키워드형](<images\stableDiffusion\텍스트이미지_문장형_키워드형.png>)

위쪽은 문장형, 아래쪽은 키워드형이다. 같은 열은 같은 seed에 해당한다.

| Seed | 문장형 관찰 | 키워드형 관찰 |
|---|---|---|
| 42 | 우주비행사는 있지만 말이 누락됨 | 우주복을 입은 사람이 말을 타는 장면이 나타남 |
| 123 | 사람이 말을 타는 장면이 나타남 | 탑승 장면과 함께 별도의 인물이 추가됨 |
| 2026 | 사람이 말을 타는 장면이 나타남 | 사람이 말을 타는 장면이 나타남 |
| 7 | 우주비행사는 있지만 말이 누락됨 | 사람이 말을 타는 장면이 나타남 |
| 99 | 우주비행사는 있지만 말이 누락됨 | 탑승 관계는 나타나지만 인물이 겹쳐 표현됨 |

**탑승 관계만 기준으로 보면 문장형 2/5장, 키워드형 5/5장이다.** 이번 키워드 조합에서는 핵심 객체인 말이 빠지는 사례가 줄었다.

다만 키워드형에도 인물 추가·중복 문제가 남았다.  
일부 배경은 달 표면보다 일반적인 사막이나 지형처럼 보여, 탑승 관계의 성공을 전체 요청의 성공과 동일하게 볼 수는 없다.

## 3. 보물상자 인페인팅 결과

이번 파일의 인페인팅 목표는 **‘금화가 들어 있는 열린 보물상자’**이다.

### 비교 프롬프트

**문장형**

> A photo of an open treasure chest filled with gold coins.

**키워드형**

> opened, treasure chest, filled, gold coins

### 원본과 마스크

![인페인팅에 사용한 해변 원본과 마스크](<images\stableDiffusion\인페인팅_입력과마스크.png>)

왼쪽은 원본, 오른쪽은 마스크이다. 흰 영역이 편집 대상이며, 중앙의 하늘·바다·모래 일부를 함께 포함한다. 두 프롬프트에는 같은 원본과 마스크를 사용했다.

### 생성 결과

![보물상자 인페인팅 비교: 위쪽 문장형, 아래쪽 키워드형](<images\stableDiffusion\인페인팅_문장형_키워드형.png>)

| Seed | 문장형 관찰 | 키워드형 관찰 |
|---|---|---|
| 42 | 장식이 있는 닫힌 상자가 나타남 | 상단이 열린 상자가 나타나지만 내부 금화는 뚜렷하지 않음 |
| 123 | 상자가 생성되지 않음 | 상자가 생성되지 않음 |
| 2026 | 닫힌 상자가 나타남 | 닫힌 서랍형 상자에 가까운 형태가 나타남 |
| 7 | 열린 상자와 내부 금화가 보임 | 열린 상자와 내부 금화가 보임 |
| 99 | 금화 모양이 구조물 외부 장식처럼 표현됨 | 보물상자보다 서랍장에 가까운 형태가 나타남 |

**두 형식 모두 seed 7에서 요청한 상태와 내용물의 관계가 가장 명확했다.** 다른 seed에서는 ‘상자’는 생성하더라도 ‘열려 있음’과 ‘금화가 안에 들어 있음’까지 함께 표현하지 못한 사례가 많았다.

특히 문장형 seed 99에서는 금화 모양이 상자 안의 내용물보다 외부 장식으로 나타났다. 객체의 존재뿐 아니라 **객체의 상태와 객체 사이의 관계**도 확인해야 함을 보여준다.

같은 seed 123에서 두 조건 모두 상자가 누락됐다는 점도 눈에 띈다. 다만 이 한 쌍의 결과만으로 초기 노이즈가 누락의 원인이라고 단정할 수는 없다.
